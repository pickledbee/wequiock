# Wequiock Presbyterian Church Website

The website for Wequiock Presbyterian Church, 4014 Wequiock Road, Green Bay, WI.

- index.html is the whole website (Home, Announcements, Membership, Give, Calendar, History, Pictures).
- apps-script/ holds the Google Apps Script that lets church members post announcements, calendar events, and urgent notices from a Google Sheet or a simple update page. These files are a backup copy; the live script runs in Google Apps Script, not on GitHub.
